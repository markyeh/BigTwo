# Big Two: Counter Battle / 大老二：對招戰鬥

**Big Two: Counter Battle** is a roguelike deck-builder that turns traditional poker into fast-paced combat. Attack and counter using card patterns to build momentum and crush enemies in tactical 1v1 duels.

**《大老二：對招戰鬥》**是一款結合牌型規則與格鬥節奏的 Roguelike 遊戲。玩家透過出牌與反擊（Counter）進行 1v1 對決，在不斷變化的規則與勢頭（Momentum）中擊敗強敵。
